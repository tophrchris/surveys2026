# AstroGuide 2026 surveys

Published web images for [AstroGuide Portfolio](https://portfolio.astroguide.space/), maintained by its gallery import and publication tools.

The files in `public/` are copied without resizing or recompression. Content-addressed versions are retained so earlier portfolio deployments remain readable. The deployment validates `public/asset-manifest.json` and the complete site size before publishing.

This repository does not contain raw astronomy source files.
